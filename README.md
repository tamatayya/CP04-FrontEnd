## 📖 Sobre o projeto

Página web desenvolvida para o **Checkpoint 04** do 1º ano de Engenharia de Software, com o objetivo de aplicar **CSS Grid Layout** na construção de uma página responsiva.

A página reúne uma seção inicial com imagens de destaque, uma galeria, depoimentos de clientes e um rodapé com informações de contato e redes sociais, tudo organizado com Grid.

---

## ✨ Funcionalidades

* 📌 Menu de navegação fixo, com efeito de desfoque e links para as seções.
* 🏠 Seção inicial com quatro imagens, texto de apresentação e botão "Saiba mais".
* 🖼️ Galeria de imagens com colunas adaptáveis e imagens ocupando uma ou duas linhas.
* 💬 Depoimentos de clientes em cards com avatar sobreposto, dispostos em zigue-zague.
* 📞 Rodapé em quatro colunas com navegação, contato e redes sociais.
* 📱 Layout responsivo: em telas pequenas os grids são reorganizados e as seções empilham.
* 🧭 Rolagem suave entre as seções.

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:

* Estruturação semântica com HTML5 (`header`, `nav`, `section`, `footer`)
* `grid-template-columns`, `grid-template-rows` e `grid-template-areas`
* Posicionamento de itens com `grid-area`, `grid-row` e `span`
* Colunas adaptáveis com `repeat`, `auto-fit` e `minmax`
* Flexbox para alinhamento de menu, ícones e rodapé
* Design responsivo com media queries
* Variáveis CSS para cores e fonte
* Menu fixo com `position: fixed` e `backdrop-filter`
* Ajuste de imagens com `object-fit`
* Aninhamento de seletores no CSS
* Navegação por âncoras e rolagem suave
